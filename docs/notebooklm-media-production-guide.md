## ١. القواعد الذهبية وإعدادات NotebookLM المعتمدة

حتى يخرج كل ملف موجزًا (35–45 ثانية) وخاليًا من الحشو والتكرار مع بطاقات الدرس:

### أ) إعدادات الفيديو في `Customise Video Overview`
1. **Format:** اختَر **`Explainer`** دائمًا — *(هذا الخيار هو الذي يُنتج **فيديو عرضيًا `16:9`** باللغة العربية؛ خيار `Short` يُخرج فيديو طوليًا `9:16` وخيار `Cinematic` لا يوفر قائمة اللغة العربية)*.
2. **Choose language:** اختَر **`العربية (العامية المصرية)`**.
3. **Choose visual style:**
   - **`Whiteboard`:** لخرائط التدفق، النطاق المحلي والدوال، والتتبع البرمجي (`video-2-1.mp4`, `video-4-2.mp4`, ودروس المحطة ١).
   - **`Classic`** (أو **`Whiteboard`**): لدروس التزييف العميق والصراع التنافسي (`video-9-1.mp4`).
4. **المدة المستهدفة (35–45 ثانية):** لا يوجد شريط طول مباشر في `Explainer`، لذا يتحقق الإيجاز عبر **عزل المصدر (`Source Isolation`)** وتثبيت قيد **`35–45 ثانية`** وبُنية من 2–3 لقطات مركزة فقط داخل البرومبت.

### ب) إعدادات الصوت في `Customise Audio Overview`
1. **Format:**
   - **`Brief`:** للمقاطع الفردية السريعة (**35–45 ثانية**، مثل `podcast-6-2.mp3` و`podcast-9-2.mp3`).
   - **`Deep dive`** مع **Length: `Short`:** للمقاطع الحوارية القصيرة بين مذيعين عندما يتطلب المفهوم حسم مقارنة أو فخًا جدليًا (**~45 ثانية** مركزة، مثل `podcast-2-4.mp3`).
2. **Choose language:** اختَر **`العربية (العامية المصرية)`**.

### ج) قواعد صارمة في كل برومبت (Channel Separation + Cognitive Load)
1. **الفصل الصارم بين القنوات (Zero Overlap):**
   - **الفيديو:** نموذج ذهني بصري حركي (تتبع أسهم، صناديق ذاكرة، حلبة تنافس) — لا يقرأ نص البطاقة.
   - **الصوت:** فخ امتحان أو إسقاط من خارج الكتاب أو حسم لخبطة مفاهيمية — لا يكرر الفيديو ولا نصوص `richText` / `flipCards`.
   - **البطاقات التفاعلية:** الممارسة الفعلية (`starterChallenge`, `predictOutput`, `spotBug`, `codeLab`, `interactiveSim`).
2. **الدخول المباشر (Cold Open):** تبدأ الثانية `0:01` فورًا بالموقف أو السؤال الخطّاف — ممنوع تمامًا أي تحية أو تعريف بالصف الدراسي.
3. **النبرة والمخاطبة المعتمدة:** مخاطبة المتعلم مباشرة وبشكل ودود كصديق مقرب بدون أي ألقاب مثل طالب أو متعلم، مع التحدث بعامية مصرية ذكية وبناء تسلسل الفهم من المعلوم اليومي للمجهول البرمجي.
4. **عزل المصادر (`Source Isolation`):** ضع مصدرًا مستقلًا لكل درس، وقبل التوليد فعّل **صح (✓) على مصدر الدرس المطلوب وحده** (أو مرّر `source_ids` في `nlm` / MCP) حتى لا يخلط NotebookLM دروسًا متجاورة.
5. **إدارة الحصة والجودة:** راجع استهلاكك عبر `nlm usage` (أو فعّل `Generate later` في الواجهة) وفعّل **`Remove watermarks`** من إعدادات الدفتر عند التصدير.

## ٥. الأتمتة عبر `gemini-notebook-mcp` (`nlm`) فور تسجيل الدخول

يتوفر داخل بيئة المشروع مهارة `.agents/skills/nlm-skill/SKILL.md` للتعامل البرمجي مع **Gemini Notebook (`nlm`)** أو أدوات **`gemini-notebook-mcp`** بمجرد تسجيل دخول صاحب المشروع:

### خطوات التشغيل القياسية
1. **تسجيل الدخول والتحقق من الحصة قبل أي توليد:**
   ```bash
   nlm login                    # تسجيل الدخول من المتصفح وحفظ الجلسة
   nlm login --check            # التأكد من صلاحية الجلسة
   nlm usage                    # فحص استهلاك نافذة الـ 5 ساعات والحد الأسبوعي (MCP: usage_get)
   ```
   *(في MCP، إذا لزم تحديث الجلسة بعد `nlm login`: استدعِ `refresh_auth()`).*
2. **تحديد معرف الدفتر ومعرف مصدر الدرس المعزول (`Source Isolation`):**
   ```bash
   nlm notebook list
   nlm source list <notebook-id>
   ```
   *(احصل على `<source-id>` الخاص بالدرس المطلوب فقط لتمريره في `--source-ids` / `source_ids` ومنع خلط الدروس).*
3. **توليد أحد الأصول الستة الاختيارية (مثالان عبر CLI أو عبر MCP `studio_create(..., confirm=True)`):**
   ```bash
   # توليد فيديو Explainer Whiteboard معزول المصدر لدرس 2.1:
   nlm video create <notebook-id> --format explainer --style whiteboard --language ar --source-ids <source-id-2-1> --focus "<برومبت video-2-1 أعلاه>" --confirm

   # توليد صوت Brief معزول المصدر لدرس 6.2:
   nlm audio create <notebook-id> --format brief --language ar --source-ids <source-id-6-2> --focus "<برومبت podcast-6-2 أعلاه>" --confirm

   # توليد صوت Deep dive Short لدرس 2.4:
   nlm audio create <notebook-id> --format deep_dive --length short --language ar --source-ids <source-id-2-4> --focus "<برومبت podcast-2-4 أعلاه>" --confirm
   ```
4. **متابعة الحالة والتنزيل والتحويل:**
   ```bash
   nlm studio status <notebook-id>
   nlm download video <notebook-id> --output video-2-1.mp4
   nlm download audio <notebook-id> --output podcast-2-4.m4a
   ```
   *(تنبيه مهم من `nlm-skill`: أمر `nlm download audio` يحفظ الصوت بصيغة `.m4a` AAC/MP4 ويرفض `.mp3` مباشرة، لذا يُحوَّل الملف محليًا إلى `.mp3` قبل إدراجه في `public/media/`؛ كما أن تنزيلات MCP تحفظ افتراضيًا داخل `~/Downloads/gemini-notebook` أو `NOTEBOOKLM_DOWNLOAD_DIR`).*
