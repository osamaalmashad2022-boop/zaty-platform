# منصة التعلّم الذاتي — تكنولوجيا المعلومات والاتصالات (3 إعدادي · ترم 1)

منصة تعلّم ذاتي عربية أصيلة (`RTL`) مصممة للموبايل أولًا لمتعلمي الصف الثالث الإعدادي في مصر (منهج 2026/2027 القائم على Python والذكاء الاصطناعي والأمن السيبراني)، بدروس مصغّرة تفاعلية (7–10 دقائق)، وتشغيل فعلي لأكواد Python في المتصفح بدون إنترنت.

## المنهج والمحتوى (v1)
- **الوحدة الأولى — الذكاء الاصطناعي ولغات البرمجة (المحطات 1–5):**
  - المحطة 1: التفكير الحاسوبي وحل المشكلات (5 دروس مصغّرة مصقولة + فيديو وترجمة + مصادر NotebookLM + بنك 40 سؤالًا).
  - المحطات 2–5: الخوارزميات والذكاء الاصطناعي، السلاسل النصية والقوائم، الدوال ذات المعاملات، ومعالجة أخطاء المدخلات (`try/except`).
- **الوحدة الثانية — الذكاء الاصطناعي والأمن السيبراني (المحطات 6–9):**
  - التنبؤ بالنموذج الخطي، الملكية الفكرية وحماية الخصوصية، الوعي السيبراني والألعاب الخطرة، والتزييف العميق `Deepfake` (هياكل ومصادر + بنك الأسئلة).

## التقنيات المستخدمة
- **الواجهة:** Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS v4 (سمة Orchid بـ RTL أصيل وخطوط `IBM Plex Sans Arabic` و`JetBrains Mono`).
- **تشغيل Python أوفلاين:** Skulpt داخل Web Worker (`public/workers/skulpt-worker.js`) مع إدخال `input()` تفاعلي وحد تنفيذ 3 ثوانٍ.
- **التخزين والـ PWA:** `Dexie` (IndexedDB) بسجل أحداث `learning_events` ونسخ احتياطي للتقدم + Service Worker (`public/sw.js`) مع دعم `Range` للوسائط.
- **الاختبارات:** Vitest + Testing Library + fake-indexeddb.

## التشغيل المحلي
```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000`.
